## Measurements

`audit.py` produced `report.json`, `matched.tsv`, `pgdp_projects.tsv`, and the files under `work/`.

The mixed-style counts in the re-verification come from two scripts run over all 285 F2 files:

- `mixed_style_both.py` produced `mixed-style-counts.txt`, which reports the token totals and the
  loose and word-character mixed-style counts.
- `resolve_mixed.py` produced `mixed-style-boundary-classes.txt`, which splits the word-character
  count into boundaries falling between two letters and boundaries falling on interior punctuation.

`tag-counts.txt` holds the opening-tag counts, generated by an inline script recorded in the session
transcript. It counts markup inside bracketed content, which is why its totals sit slightly above
`report.json`.

## Reproducing

`/workspaces/gutenberg-corpus`, and `/workspaces/standardebooks-corpus`. They only read. Counts
